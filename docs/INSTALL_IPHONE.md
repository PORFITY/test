# Установка на iPhone

Понадобятся Mac с **Xcode 16+** и iPhone с iOS 17+. Для установки на свой телефон достаточно **бесплатного Apple ID** (Personal Team):
приложение будет работать 7 дней, затем его нужно переустановить из Xcode. Платный Apple Developer Program ($99/год) даёт год подписи и TestFlight.

## Вариант A. Через Xcode (рекомендуется)

1. Откройте `ios/MealPlanner/MealPlanner.xcodeproj` (если меняли `project.yml` — выполните `brew install xcodegen && cd ios/MealPlanner && xcodegen generate`).
2. Target **MealPlanner → Signing & Capabilities**: включите *Automatically manage signing*, выберите свой **Team** (Xcode → Settings → Accounts → добавьте Apple ID).
3. Смените **Bundle Identifier** на уникальный (например `com.<ваше-имя>.mealplanner`).
4. Подключите iPhone кабелем, включите на нём *Настройки → Конфиденциальность и безопасность → Режим разработчика*, выберите iPhone как destination и нажмите **Run**.
5. На iPhone: *Настройки → Основные → VPN и управление устройством* → доверьтесь своему сертификату разработчика.

Пакет `MealCore` подключён как локальная зависимость (`../MealCore`) — ничего скачивать не нужно.

## Вариант B. Неподписанный IPA из CI → AltStore / Sideloadly

GitHub Actions (`.github/workflows/ios.yml`) собирает **неподписанный** `MealPlanner-unsigned.ipa` (артефакт запуска `ios-artifacts`).
Подписанный IPA без вашего сертификата получить нельзя. Установить неподписанный файл можно, переподписав его своим Apple ID:
[Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io) (те же 7 дней для бесплатного Apple ID).

## Вариант C. TestFlight (нужен платный аккаунт)

Xcode → Product → Archive → Distribute App → App Store Connect → TestFlight. Предварительно создайте приложение в App Store Connect с вашим Bundle ID.

## Подключение backend (необязательно)

1. Запустите backend по [BACKEND.md](BACKEND.md) за публичным HTTPS-адресом.
2. В Xcode: Target → Build Settings → *User-Defined* → `BACKEND_URL` = `https://api.example.com` (или впишите в `ios/MealPlanner/project.yml` и выполните `xcodegen generate`).
3. Если на сервере задан `API_TOKEN`, введите его в приложении: *Ещё → Настройки → Сервер → Токен* (хранится в Keychain).

Без backend приложение работает: магазины — Apple Карты, цены — из CSV/JSON и ручного ввода (или ориентиры с пометкой), ассистент — локальные команды.

## Первый запуск

Приложение предложит найти магазины (разрешение на геопозицию «при использовании»; можно отказаться и ввести адрес) → бюджет, период, люди, приёмы пищи →
**аллергены (обязательный шаг)** → вкусы → цель и режим покупок → техника и посуда → «Создать рацион».
Нет цен магазина? Загрузите CSV/JSON в карточке магазина, введите цены в *Ещё → Мои цены* или разрешите расчёт по ориентирам (результат будет помечен).

### Формат CSV для прайса
```
Название;Цена;Вес;Бренд;Состав
Рис круглозерный 900 г;129,90;900 г;Бренд;рис
Молоко 3,2% 930 мл;89;930 мл;;молоко цельное
```
Колонки распознаются по названиям (ru/en), разделитель `;`, `,` или таб, десятичная запятая допустима. Строки с ошибками не пропускаются молча: приложение сообщает их число и первую причину.
